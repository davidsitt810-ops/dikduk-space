# dikduk-space

The pizmonim dikduk checker: a fit-score server (two wav2vec2 ears + trained Hebrew-letter and vowel heads) and its
lab page. The same files make a Hugging Face Space (Docker) — see `README.md` — or run on Google Colab for a test:

**Colab:** open `Dikduk.ipynb` in Colab and run the one cell; it prints a public address (a `trycloudflare.com`
tunnel to the notebook) for the lab page and `/try` for a visitor. Lives while the cell runs.

Nothing here touches thepizmonim.com.
